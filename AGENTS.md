# AGENTS.md

Personal site of fudō-ryū (fudoryu.dev): Astro 7, MDX, Tailwind 4, Observable Plot. Fully static.

## Commands

- Node 26 via nvm (`nvm use` reads `.nvmrc`); npm only — don't add other lockfiles.
- `npm run dev` / `npm run build` (output in `dist/`).
- `npm run verify` — prettier check, eslint, `astro check`, build. Must pass before you're done; CI runs the same.
- `npm run format` to fix formatting.

## Conventions

- Content lives in `src/content/{posts,experience,projects}`; schemas in `src/content.config.ts` (a bad front-matter field fails the build). Posts are `.md`, or `.mdx` only when they embed a component.
- Site name, links and tagline: `src/data/site.ts`. The author's real name is deliberately withheld — never add it.
- Colours come from tokens in `src/styles/tokens.ts` / `global.css`; don't hard-code hex values. One accent colour, used sparingly.
- Import from `src` with the `@/` alias.
- Chart components (`src/components/viz/`) must load their JS lazily (on visibility), not on page load.
- `trailingSlash: 'always'` — internal links end with `/`.

## Gotchas

- `src/data/mei.ts` is generated by `scripts/extract-mei.py` (needs Python `fonttools`). Don't edit by hand; it's excluded from Prettier.
- After changing `astro.config.ts` (e.g. Expressive Code styles), delete `.astro/` — cached Markdown can keep a stale stylesheet hash.
- Deployed to Cloudflare Pages (static `dist/`). Response headers and caching live in `public/_headers`.
- OG images are rendered at build time with satori (`src/lib/og.ts`, `src/pages/og/`).
